# Brief: terminology pass, existence / being / nothingness

The translation of Kuki's 偶然性の問題 used "being" for both 存在 and 有, and "nothing" for 無. The binding rule is now:
| Japanese | English |
|---|---|
| 存在 | existence (存在する: exist; 存在者: the existent) |
| 非存在 | non-existence |
| 有 | being |
| 無 | nothingness (ordinary negation 無い / 無し stays "there is no", "without", "lack") |
| 眞の存在 | true existence |
| 極限的存在 | limit-existence |
| 虛無性 | nihility |
| 存在論 / 存在論的 | ontology / ontological (unchanged) |
